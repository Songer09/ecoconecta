# Datos de ejemplo del piloto

El 21 de noviembre de 2026 se cargaron ejemplos mediante la API remota existente, usando las cuentas `Demo Gerson` y la zona `Villas de San Pablo · prueba piloto`.

- Solicitante: diez solicitudes propias, seis orgánicas y cuatro reciclables. Direcciones, materiales, cantidades estimadas y coordenadas están identificados como ficticios.
- Coordinación de huerta: dos solicitudes recibidas, una en revisión, una asignada y dos programadas. Además, tres necesidades de ejemplo: semillas, guantes y recipientes para compostaje.
- Coordinación de reciclaje: una solicitud recibida y tres en revisión.
- Recolector de huerta: tres asignaciones, dos programadas. Una incluye un pesaje de ejemplo de 3,5 kg pendiente de verificación.
- Administración: dos borradores de eventos claramente identificados como DEMO para revisar y publicar desde el panel.

Las cantidades anteriores describen exclusivamente esta carga; las bandejas también pueden contener solicitudes creadas previamente por otros usuarios. No se cambiaron solicitudes anteriores. Se utilizaron las transiciones y las validaciones de permisos de la API, incluidas las coberturas y franjas configuradas.

No se publicaron tarifas ni se acreditaron puntos: el piloto no tenía reglas de puntos configuradas. Las coordenadas de ejemplo no identifican viviendas reales y no deben usarse para despachar una recolección real. El mapa actual muestra el centro aproximado del barrio; todavía no ubica cada solicitud.
